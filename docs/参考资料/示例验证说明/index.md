# 示例验证说明

本表记录学习资料的验证范围。代码能编译、示例行为正确、框架集成通过和生产环境可用是不同结论；各案例中的预期输出仍需在自己的学习环境核对。

## 当前版本与验证状态

通用学习主线为 Java 25，业务兼容要求单独核对。下表中 Java 8 目标的检查仍是其实际验证证据，不能据此标记 Java 25 或新框架组合已运行。当前未检测到本机 JDK 25，Java 25 命令、构建和新增现代特性尚待对应环境执行。

## 已具备的核对证据

公开的 15 个专题目录均包含 README 与典型案例；15 另有四个独立单元的路线和案例。案例开头有技能迁移表，知识点先于综合案例，README 链接到对应章节；本地路径、章节锚点、代码围栏和 POM XML 已检查。主线依赖组合调整后仍需在 JDK 25 环境重做运行验证。

| --- | --- | --- |

15 的聚合值通过固定输入的关系运算独立核对，窗口计数按输入事件时间计算，没有把这种核算称为 Spark/Flink 执行。

## 动手时保存的证据

1. 记录工具、框架、数据库和连接器版本，以及执行目录。
2. 保存输入、预期结果、实际输出和必要日志。
3. 将正常、边界和故障路径分别验证，说明失败发生在哪一步。
4. 修正假设或实现后，用同一输入重复核对。
