# 示例验证说明

本表记录学习资料的验证范围。代码能编译、示例行为正确、框架集成通过和生产环境可用是不同结论；各案例中的预期输出仍需在自己的学习环境核对。

## 当前版本与验证状态

通用学习主线为 Java 21，业务兼容要求单独核对。2026-10-29 使用本机 OpenJDK 21.0.13.0.2 与 `javac --release 21`，完成 16 次编译和 24 次运行，连同两次工具版本检查共 42 条命令符合预期；其中 5 次运行验证预期失败。编译覆盖 31 个仓库 Java 文件，另有 JDBC 方法包装和两项临时边界检查。

## 已具备的核对证据

公开的 15 个技术专题目录均包含 README 与典型案例，00 目录另提供能力成长指南；15 另有四个独立单元的路线和案例。案例开头有技能迁移表，知识点先于综合案例，README 链接到对应章节；本地路径、章节锚点、代码围栏和 POM XML 已检查。纯 Java 验证与框架、数据库和引擎联调分别记录。四个 Maven 学习工程尝试离线 verify，因插件依赖或父 POM 缓存不完整均未完成；没有将这些结果记为源码编译错误，也没有下载依赖补齐环境。

15 的聚合值通过固定输入的关系运算独立核对，窗口计数按输入事件时间计算，没有把这种核算称为 Spark/Flink 执行。

## 动手时保存的证据

1. 记录工具、框架、数据库和连接器版本，以及执行目录。
2. 保存输入、预期结果、实际输出和必要日志。
3. 将正常、边界和故障路径分别验证，说明失败发生在哪一步。
4. 修正假设或实现后，用同一输入重复核对。
