# Redis 缓存

### 1. 权威数据与缓存范围

**业务问题：** 展示结果从哪里来，缓存丢失或过期后靠什么恢复？

**概念与保证：** 数据库中的权威记录与缓存副本有不同职责。命中只表示副本存在，不证明最新或仍有权访问。

**项目中看什么：** 确认键的租户/项目范围、值的来源、允许陈旧时间，以及哪些决策必须读取权威数据。

**教程与讲解：** [廖雪峰 Redis](https://liaoxuefeng.com/books/java/springboot/integration/redis/index.html)；[缓存职责](/01-Java学习路线/08-缓存、消息与服务协作/Redis缓存/典型案例/#一-缓存保存可重建的结果)。

### 2. Redis 常用操作

**业务问题：** 缓存怎样写入、过期和删除，哪些运行条件会让它提前消失？

**概念与保证：** SET/GET/EX/TTL/DEL 表达键值生命周期；TTL 与内存淘汰不同，复制与故障切换也不保证副本永不丢失。

**项目中看什么：** 沿客户端和生效配置确认访问入口、键结构、过期策略与部署角色；按访问方式理解字符串、哈希和集合。

**教程与讲解：** [Redis 字符串](https://redis.io/docs/latest/develop/data-types/strings/)、[过期](https://redis.io/docs/latest/commands/expire/)、[淘汰](https://redis.io/docs/latest/develop/reference/eviction/)；[键值生命周期](/01-Java学习路线/08-缓存、消息与服务协作/Redis缓存/典型案例/#二-用-redis-保存值并设置过期时间)。

### 3. 旁路缓存与失败

**业务问题：** 更新成功后为什么还可能读到旧值，Redis 不可用时数据库能否承受回源？

**概念与保证：** 未命中查库并回填、写库后失效仍有并发交错。缓存正确性要结合允许陈旧窗口、失效恢复和回源容量定义。

**项目中看什么：** 追读路径、更新提交点、删除或回填逻辑，检查热点、空值缓存和降级是否仍满足业务结果。
