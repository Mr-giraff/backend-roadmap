# 示例验证说明

本表记录学习资料的验证范围。代码能编译、示例行为正确、框架集成通过和生产环境可用是不同结论；各案例中的预期输出仍需在自己的学习环境核对。

## 已完成的核对

公开的 14 个目录均包含 README 与典型案例。案例开头有技能迁移表，知识点先于综合案例，README 链接到对应章节；本地路径、章节锚点、代码围栏和 POM XML 已检查。

| 路线 | 已验证的部分 | 仍需对应环境验证 |
| --- | --- | --- |
| 01 Java | 20 组概念示例按 Java 8 目标编译运行；预期编译失败与缺文件路径核对 | 真实 JDK 8、深入 JVM 诊断 |
| 02 工程 | 单文件/单模块普通 Java 编译运行；原双模块已有离线 Maven 构建、运行和配置验证 | 新单模块 Maven 构建、IDE 与发布环境 |
| 03 服务开发 | 完整 Spring 学习工程、POM 与请求响应按配置静态核对 | Spring 启动、HTTP 联调及完整请求链 |
| 04 分层 | 纯 Java 业务例子编译运行，空名称、重复与不存在路径验证 | 真实数据库、事务与并发持久化 |
| 05 数据库 | JDBC 示例按 Java 8 目标编译；SQL 输入、预期结果和脚本顺序静态核对 | MySQL 约束、查询计划、迁移与并发行为 |
| 06 事务 | SQL、双连接时间线与 Spring 配置按官方语义静态核对 | MySQL 提交/锁、Spring 代理与回滚的实际执行 |
| 07 并发 | 完整程序及正文最小例子编译运行，多轮检查计数、队列拒绝、超时取消和上下文清理 | 真实负载、数据库连接与远程资源联动 |
| 08 缓存消息 | 命令、HTTP JSON、确认与幂等时序静态核对 | Redis、RabbitMQ、MySQL 与故障重投 |
| 09 分布式 | 幂等、Outbox、消费提交与恢复时序静态核对 | 多进程、数据库、消息与故障注入 |
| 10 系统设计 | 吞吐、积压恢复、存储及分位数样本计算核对 | 压测、权限、领取租约与恢复方案的实现 |
| 11 测试 | 纯 Java 规则和手工校验运行；JUnit/MVC 的依赖和类定义静态核对 | JUnit、MockMvc、真实数据库测试 |
| 12 安全 | 纯 Java 授权模型与拒绝路径运行 | 真实身份认证、Session/Token、安全过滤链与跨服务授权 |
| 13 运维 | 本地 HTTP 演示源码按 Java 8 目标编译，命令与恢复步骤静态核对 | 端口运行、JVM 诊断、发布回滚、备份恢复 |
| 15 大数据 | 固定输入的聚合与窗口边界独立核算 | Spark/Hive/Flink SQL、调度、Checkpoint 与实际分析引擎 |

Java 编译核对使用本机可用 JDK，并以 `--release 8` 限定语言、API 与字节码目标，不等于已经在真实 JDK 8 上运行。纯 Java 样本不证明同一业务在多实例或真实持久化下正确。

15 的聚合值通过固定输入的关系运算独立核对，窗口计数按输入事件时间计算，没有把这种核算称为 Spark/Flink 执行。

## 动手时保存的证据

1. 记录工具、框架、数据库和连接器版本，以及执行目录。
2. 保存输入、预期结果、实际输出和必要日志。
3. 将正常、边界和故障路径分别验证，说明失败发生在哪一步。
4. 修正假设或实现后，用同一输入重复核对。
